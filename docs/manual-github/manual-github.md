\# Manual de Usuario de GitHub



\## 1. Repositorio del proyecto



El proyecto SistemaVentaMassWeb se encuentra alojado en GitHub y contiene el backend, frontend, documentación, workflows de GitHub Actions y archivos de despliegue Docker.



\## 2. Estructura del repositorio



\- backend: contiene el proyecto Spring Boot.

\- frontend: contiene el proyecto Angular.

\- .github/workflows: contiene los scripts de CI/CD.

\- docs/manual-github: contiene el manual de gestión de GitHub.

\- docker-compose.yml: permite ejecutar el sistema mediante Docker.



\## 3. Gestión de issues



Los issues se utilizaron para registrar las tareas principales del proyecto. Cada issue contiene descripción, responsable, prioridad, sprint, fecha de inicio, duración y checklist.



\## 4. Tablero Kanban



El tablero Kanban permitió visualizar el estado de cada issue. Los estados utilizados fueron Backlog, In progress, Ready, In review y Done.



\## 5. Ramas



Las ramas se utilizaron para trabajar funcionalidades sin afectar directamente la rama principal main.



\## 6. Commits



Los commits permitieron registrar los cambios realizados durante el desarrollo del sistema.



\## 7. Pull Requests



Los Pull Requests permitieron revisar los cambios antes de integrarlos a la rama principal.



\## 8. GitHub Actions



GitHub Actions permitió automatizar la validación de estructura, compilación del backend, compilación del frontend y build completo del sistema.



\## 9. Docker



Docker permitió desplegar el sistema completo mediante contenedores para frontend, backend y base de datos MySQL.
